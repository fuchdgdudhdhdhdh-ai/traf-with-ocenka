# Referral bot v5 — проверка рейтинга + 5 каналов

Новая версия трафбота: вся механика старого бота (капча, рефералы, выплаты, админка),
но реферал проходит проверку рейтинга профиля, холда нет, награда в долларах.

## Как это работает

1. `/start` (по реф-ссылке `?start=ref_ID`) → эмодзи-капча.
2. Проверка рейтинга профиля (0–100, критерии в `rating.py`, порог по умолчанию 80).
3. Рейтинг **≥ порога**: пользователь получает 5 каналов. Подписка проверяется только на
   публичном канале №3, остальные 4 (частные) не проверяются. После проверки пригласившему
   сразу начисляется 1.4$ (без холда).
4. Рейтинг **ниже порога**: сообщение, что пригласившему награда не начислится, кнопки
   «Критерии оценки» и «Перейти к боту» (чтобы тоже мог приглашать).
5. Перед ботом — правила → «Далее» (всплывающее предупреждение) → повторное предупреждение
   о бане → «Прочитал и согласен» → главное меню.
6. Баланс показывается в $ и в ₽ (по курсу из админки, по умолчанию 1$ = 80 ₽).
7. Вывод: карта (комиссия 45 ₽), СБП, чек CryptoBot (вручную: админ присылает ссылку на чек).

## Запуск (Render)

Переменные окружения:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `SUPERADMIN_IDS` | Telegram ID админов через запятую |
| `DATABASE_URL` | строка подключения PostgreSQL |
| `CRYPTO_PAY_TOKEN` | (необязательно) токен Crypto Pay из @CryptoBot — тогда чеки выдаются автоматически |
| `CRYPTO_PAY_TESTNET` | (необязательно) `1` — тестовая сеть Crypto Pay |

Команда старта: `python main.py` (таблицы создаются автоматически).

Бот должен быть **администратором публичного канала** (канал №3), иначе подписка не проверится.

## Настройка

Всё остальное — в Telegram: `/admin` → «Каналы» (5 слотов, для №3 — ещё ID канала),
«Настройки» (порог рейтинга, награда, курс, комиссия, открыть/закрыть бота и выплаты),
«Тексты» (правила, меню, FAQ, критерии).

## Дополнительно

- **Поддержка:** кнопка «🆘 Поддержка» → тикеты; админ отвечает из `/admin` → «Тикеты».
- **Рассылка:** `/admin` → «Рассылка» (текст/фото/видео, с подтверждением).
- **Рефералы:** в карточке пользователя → «Рефералы»: 🗑 убрать со списанием награды, 🚫 то же + бан.
- **Списание при отписке:** `/admin` → «Настройки» → переключатель (по умолчанию выключен).
  Бот раз в 10 минут проверяет подписку на публичный канал у рефералов за последние N дней
  и списывает награду у отписавшихся.
- **Чеки CryptoBot:** без `CRYPTO_PAY_TOKEN` админ присылает ссылку на чек вручную; с токеном
  чек создаётся автоматически (USDT, привязан к Telegram ID получателя).
- `render.yaml` — готовая конфигурация для Render (сервис + PostgreSQL).
